# Test Case 3: three-dimensional PVP electrospinning

This case models a polyvinylpyrrolidone solution in a conventional
three-dimensional electrospinning setup. It uses a 16 cm collector distance,
a 0.005 cm nozzle radius, a rotating nozzle perturbation, bead insertion,
and the Maxwell rheological model.

The material and operating parameters are based on the PVP reference case
described in the scientific manual.
