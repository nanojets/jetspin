# Test Case 7: evaporation and rotating electric field

This case combines a three-dimensional Maxwell fluid, aerodynamic drag,
solvent evaporation, and an orthogonal rotating electric field. The initial
polymer fraction is 0.025 and `evaporation tconstant 1` selects the Yarin
2001 relaxation-time law.

It is a coupled JETSPIN regression example, not a quantitative reproduction
of the original 6 wt% aqueous-PEO calculation.
