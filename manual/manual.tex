\begin{center}
\textbf{\Large{}{}About JETSPIN}{\Large{} }
\par\end{center}{\Large \par}

\bigskip{}

The code is licensed under Open Software License v. 3.0 (OSL-3.0).
The full text of the licence can be found on the website: http://opensource.org/licenses/OSL-3.0

If results obtained with this code are published, an appropriate citation
would be:

Marco Lauricella, Giuseppe Pontrelli, Ivan Coluzza, Dario Pisignano,
Sauro Succi, JETSPIN: A specific-purpose open-source software for
simulations of nanofiber electrospinning, \textit{Computer Physics
Communications}, 197 (2015), 227-238.

The models implemented in JETSPIN are reviewed, in the broader context of
electrospinning and solution blowing, in the following works, which may
also be cited:

Marco Lauricella, Sauro Succi, Eyal Zussman, Dario Pisignano, Alexander L.
Yarin, Models of polymer solutions in electrified jets and solution
blowing, \textit{Reviews of Modern Physics}, 92 (2020), 035004.

Alexander L. Yarin, Filippo Pierini, Eyal Zussman, Marco Lauricella,
Modelling of nanofiber formation processes, in \textit{Materials and
Electro-mechanical and Biomedical Devices Based on Nanofibers}, Springer
(2024), 237-326.

The revisions of this manual for version 2.0, like the Markdown
documentation in the \textit{docs} sub-directory, were written with the
assistance of an artificial-intelligence agent and reviewed against the
source code.

\section*{Scope of Chapter}
