\section{Test Case 1: 1-D case}

This input file (located in the \textit{input-1} sub-directory) provides
the dimensionless parameter values $Q=12$, $V=2$ (printed as \texttt{Phi})
and $F_{ve}=12$ in the definition of Reneker et al.\ ($F_{ve}\simeq1727.5$
with the definition of Tab.~\ref{tab:tabella-adimensionale}; the program
prints both), which have been already used as reference case in Refs \cite{reneker2000bending,pontrelli2014electrospinning}.
In the OpenACC build this one-dimensional case runs the CPU build's code on
the host and launches no kernel: one-dimensional systems do not take the
device step, and the jet keeps its single bead.
