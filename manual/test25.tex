\section{Test Case 25: evaporative counterpart of Test Case 24\label{sec:Test-Case-25}}

Test Case 25 is Test Case 24 with evaporation enabled and nothing else
changed.  The two input files differ by exactly one line,
\texttt{evaporation no} against \texttt{evaporation yes}.  Everything else is
shared: the canonical electrostatic parameters
(\texttt{density charge 44000}, \texttt{collector distance 16},
\texttt{external potential 30.02076857}), Maxwell rheology, stochastic Platen
air drag, nozzle insertion and collector removal from Test Case 23, the
single-nozzle-bead start and print directives from Example 3, and Example 5's
refinement cadence.

This case does not currently run to completion, and that is its purpose.  Test
Case 24 was originally intended to carry Test Case 23's Yarin evaporation
together with its rheology, but evaporation does not survive the corrected
electrostatics.  Rather than dropping it silently, the two configurations are
kept as separate inputs so that the failure remains reproducible with a
one-keyword difference.  Test Case 24 completes six million steps cleanly with
571 active beads in a stationary oscillation, whereas Test Case 25 stops at
step 1,078,685, about 1\% of its target, on the code's own numerical
instability check, with a stress NaN at bead 30 at $x=12.68$ cm and 262 active
beads.

Two observations narrow the search.  The failing run never engages the
persistent accelerator path, so the failure belongs to the ordinary host
integrator and is not an accelerator artifact.  And the bending instability
develops normally up to the failure: at step 800,000 the jet is at an off-axis
distance of 1.66 cm with a bending angle of 27 degrees and 48 active beads.

The stress-NaN signature is the same one produced, by two different routes, by
the polymer-mass-fraction defect and the cross-section thinning defect that
Test Case 24's investigation identified and addressed.  The first hypothesis
to test is therefore whether the cross-event compounding of the cross-section
radius resurfaces under genuine bending: the refinement-cadence workaround
that contains it was validated on a configuration whose cross-section field
was far smoother than it is here.

This case should be used as the reproducer for that open instability, not as a
validation or performance reference, and it is excluded from the short smoke
and regression matrices.  The input is stored in
\texttt{examples/input-25/input.dat}.
